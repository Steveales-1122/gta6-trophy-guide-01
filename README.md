An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: 1 Platinum, 2 Gold, 6 Silver, 46 Bronze, 28 hidden. A checklist with progress saved in the browser, a six-stage roadmap to the Platinum, missable flags, per-trophy guides in this entry's own words with cited sources, and export/import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. The app is static files under `app/` — no build step, no network at run time. It works with the network off.

## What it does

- **Checklist** — every trophy with its official name, description and grade; tick to earn, with the time recorded. Filters by kind (story, missable, collectibles, activities, robberies, combat, exploration, money, secret) and a search box.
- **Roadmap** — six stages in order: the story, stranger strands, seeing all of Leonida, crime, mastering activities, then secrets and the Platinum.
- **Missables** — the one confirmed missable trophy (Positive Mental Attitude: Lucia's Chapter 1 meditation spot) and the save discipline that protects it. The game has no mission replay, so the guide asks for a manual save at the start of every chapter.
- **Stats** — progress by grade, by kind and by stage.
- **Planner** — what to do next from where you are, plus the long grinds (250 stunts, 42 shooting-range golds, 100 WAiNK spots) to start early.
- **Surprise me** — a random unearned trophy for tonight.
- **History** — every earned trophy with its timestamp.
- **Settings** — a spoiler switch that hides story trophy names and descriptions until earned, JSON and Markdown export, JSON import, and reset.
- **Keyboard shortcuts** — `1`–`9` switch views, `/` searches, `E` exports, `?` shows help.

## Sources

Official names, descriptions and grades are PlayStation's, taken from Exophase on 18 November 2026 and cross-checked with PSNProfiles and TrueAchievements. Every guide is written for this entry, in its own words, and cites its sources beside each trophy. No Rockstar Games logo or official artwork is used.
